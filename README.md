# 아파트 실거래가 조회기

국토교통부 아파트 매매 실거래가 API로 원하는 아파트 단지들의 실거래가를 모아서 비교하는 프로젝트입니다.

## 진행 상황

- [x] 1단계: API 연결 확인과 데이터 저장 (`fetch.py`)
- [x] 2단계: 단지 검색과 데이터 정리 (`analysis.py`)
- [x] 3단계: 비교 화면 (`app.py`, Streamlit) 첫 버전
- [ ] 4단계: 공유 준비

## 처음 한 번만 하는 준비 (Windows)

1. 파이썬이 설치되어 있어야 합니다. 명령 프롬프트(cmd)에서 `python --version`으로 확인하세요.
2. 이 폴더에서 필요한 패키지를 설치합니다.

   ```
   cd /d D:\AIworking\부동산실거래가조회기
   python -m pip install -r requirements.txt
   ```

3. 인증키 파일을 만듭니다. `.streamlit\secrets.toml.example`을 같은 폴더에 `secrets.toml`로 복사하고,
   공공데이터포털에서 받은 **일반 인증키**를 넣으세요.
   이 파일은 `.gitignore`에 들어 있어서 GitHub에 올라가지 않습니다.

## 비교 화면 열기

```
cd /d D:\AIworking\부동산실거래가조회기
python -m streamlit run app.py
```

브라우저가 자동으로 열립니다(안 열리면 http://localhost:8501). 끝낼 때는 명령 프롬프트에서 Ctrl+C.

- 왼쪽 **데이터 업데이트**에서 지역을 고르고 **받기**를 누르면 화면에서 바로 데이터를 받습니다.
- 위쪽 칸에 단지 이름이나 동 이름을 입력해서 비교할 단지를 여러 개 고릅니다.
- **관심 단지로 저장**을 누르면 다음에 열 때 자동으로 선택됩니다(`data\favorites.json`).
- 탭: 시세 추이(월별 중앙값 + 개별 거래 점), 평형별 비교, 평당가 비교, 최근 거래.

## 명령어로 데이터 받기

```
python fetch.py --list                  # 받을 수 있는 지역 목록
python fetch.py 강남구 송파구            # 두 구의 최근 36개월 거래 받기
python fetch.py 강남구 --months 60       # 최근 5년
python fetch.py 안양시 수원시 분당구      # 시 이름으로 쓰면 소속 구를 모두 받음
```

- 받은 데이터는 `data\trades.db` 파일(SQLite)에 저장됩니다.
- 다시 실행하면 이미 받은 달은 건너뛰고, 최근 3개월만 새로 받습니다.
  실거래 신고는 계약 후 30일 안에 하면 되고, 해제(취소) 신고도 나중에 들어오기 때문입니다.
- 한 구의 1개월치가 API 호출 1번입니다. 개발계정 인증키의 하루 호출 한도(보통 1만 번) 안에서 충분합니다.

## 알아두면 좋은 점

- 이 API에는 실제 거래된 가격만 있습니다. 네이버 부동산 같은 호가(매물 가격)는 없습니다.
- 면적은 전용면적(㎡)만 나옵니다. 호갱노노의 "34평"처럼 공급면적 기준 평형과는 다릅니다.
- 평형은 전용면적의 정수 부분으로 묶습니다(84.97㎡, 84.43㎡ → 전용 84㎡).
- 평당가는 **전용면적 기준**입니다. 호갱노노 등 공급면적 기준 평당가보다 높게 나옵니다.
- 거래금액 단위는 만원입니다. `cancel_type`이 `O`인 거래는 해제(취소)된 거래입니다.
- 지역은 서울 25개 구와 안양(만안·동안), 광명, 분당, 수지, 수원(장안·권선·팔달·영통), 의왕, 군포가 `regions.py`에 들어 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `app.py` | 비교 화면 (Streamlit) |
| `analysis.py` | 단지 검색, 평형 묶기, 평당가·추이 계산 |
| `fetch.py` | 명령어로 지역 데이터를 받아서 저장 |
| `molit_api.py` | 국토부 API 호출과 XML 해석 |
| `db.py` | SQLite 저장 |
| `regions.py` | 시군구 이름과 코드 목록 |
